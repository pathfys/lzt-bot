# offerbot — `.buy` для подарков Telegram

Юзербот: подключается к **твоему** аккаунту (MTProto), ловит команду, которую ты
сам напечатал в любом чате, и превращает её в аккуратный оффер с **превью
подарка** — большой картинкой над текстом.

```
.buy stars 1500 plushpepe 1234 en
```

превращается в:

```
┌─────────────────────────────┐
│   [ картинка Plush Pepe ]   │   ← превью, прибито к ссылке подарка
└─────────────────────────────┘
🟢 BUY — Plush Pepe #1234
💵 Price: 1,500 ⭐ (≈ $23)
🤝 Escrow / hold — fine
✍️ DM: @your_username
```

Со стороны это твоё собственное сообщение, а не пост бота: команда
**редактируется на месте**, поэтому работает и в чатах, куда ботов не пускают,
и в чатах со слоумодом (редактирование слоумодом не ограничено).

## Формат команды

```
.buy  <stars|gram>  <цена>  <подарок>  <номер>  <en|ru>
.sell <stars|gram>  <цена>  <подарок>  <номер>  <en|ru>
```

Парсер намеренно терпимый — команду набирают с телефона посреди сделки.
Все строки ниже дают один и тот же оффер:

```
.buy stars 1500 plushpepe 1234 en
.buy 1500 stars plushpepe 1234 en
.buy stars 1500 PlushPepe-1234 en
.buy stars 1500 plushpepe #1234 en
.buy 1500stars plush pepe 1234 en
.buy ⭐ 1500 plush-pepe 1234 english
```

Что ещё понимает:

| Элемент | Варианты |
|---|---|
| Префикс | `.` `!` `/` |
| Сторона | `buy` `sell` `b` `s` `куплю` `продам` `покупаю` `продаю` |
| Валюта | `stars` `star` `⭐` `звёзды` · `gram` `ton` `💎` `тон` |
| Цена | `1500` · `12.5` · `12,5` · `1500stars` |
| Подарок | `plushpepe` · `Plush Pepe` · `plush-pepe` · `PlushPepe-1234` |
| Номер | отдельным числом или `#1234` |
| Язык | `en` `eng` `english` · `ru` `rus` `русс` |

Валюту и язык можно писать в любом месте команды. Единственная реальная
двусмысленность — цена и номер подарка оба числа; она решается по порядку из
документации: **первое число — цена, последнее — номер**. `#1234` снимает
вопрос совсем.

Если команда не разобралась, она превращается в короткую подсказку, которая
через `ERROR_TTL` секунд сама удаляется — чат остаётся чистым.

## Установка

```bash
git clone <this repo> && cd lzt-bot
python3 -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env            # вписать TG_API_ID и TG_API_HASH
```

`TG_API_ID` / `TG_API_HASH` берутся на <https://my.telegram.org/apps>.

Посмотреть карточку, **не подключаясь к Telegram вообще**:

```bash
python -m offerbot check '.buy stars 1500 plushpepe 1234 en'
```

Запуск:

```bash
python -m offerbot                 # первый вход спросит телефон и код
python -m offerbot login           # выдаст session string для сервера
```

## Как сделано превью

Превью не оставлено на усмотрение Telegram. Ссылка подарка прикрепляется
явно, как `InputMediaWebPage`:

```python
await client(EditMessageRequest(
    peer=peer, id=event.id,
    message=text, entities=entities,
    media=InputMediaWebPage(
        url="https://t.me/nft/PlushPepe-1234",
        force_large_media=True,   # большая картинка
        optional=True,            # нет страницы — пост всё равно уйдёт
    ),
    invert_media=True,            # картинка НАД текстом
))
```

Это даёт три вещи, которых не даёт обычная ссылка в тексте: превью привязано
именно к подарку (а не к первой попавшейся ссылке в сообщении), картинка
крупная, и она стоит над текстом. `optional=True` — страховка: если номера
подарка не существует или Telegram не смог забрать страницу, сообщение
отправится без картинки, а не упадёт.

Ссылка подарка: `https://t.me/nft/<Slug>-<номер>`, где slug — название
коллекции в CamelCase без пробелов и апострофов (`Durov's Cap` → `DurovsCap`).
Известные коллекции лежат в `offerbot/gifts.py`; новая добавляется одной
строкой или через `GIFT_ALIASES_FILE`. Незнакомое название всё равно даст
ссылку, но карточка честно припишет «проверь ссылку».

## Структура

| Файл | Зачем |
|---|---|
| `offerbot/parser.py` | разбор команды → `Offer` |
| `offerbot/gifts.py` | slug'и коллекций, ссылка `t.me/nft/...` |
| `offerbot/render.py` | карточка и тексты ошибок на en/ru |
| `offerbot/money.py` | форматирование чисел без системных локалей |
| `offerbot/rates.py` | курс TON с кэшем; падает в «без курса», а не в ошибку |
| `offerbot/poster.py` | доставка в чат, превью, обработка ошибок Telegram |
| `offerbot/handlers.py` | хендлер исходящих сообщений |
| `offerbot/config.py` | конфиг из окружения |

Вся логика, кроме `poster.py` и `handlers.py`, — чистая и тестируется без
сессии:

```bash
pip install -r requirements-dev.txt
python -m pytest tests -q
```

## Безопасность и лимиты

- **Session string = полный доступ к аккаунту.** Без пароля и без запроса 2FA.
  Не коммить, не пересылать, не показывать на скриншоте. `.gitignore` уже
  закрывает `.env`, `*.session` и `session*`.
- **Работай с отдельного аккаунта**, а не с основного, на котором лежат
  подарки.
- Юзерботы — серая зона в ToS Telegram. Редактирование своих сообщений в
  чатах, где ты сам сидишь, обычно проходит спокойно; массовая рассылка и
  письма в ЛС незнакомым людям — главный путь к `PeerFloodError` и
  ограничению аккаунта. Этот бот намеренно умеет только одно: оформить то,
  что ты и так собирался написать.
- `FLOOD_SLEEP_THRESHOLD` отдаёт короткие флуд-ожидания Telethon; длинные
  возвращаются тебе уведомлением с числом секунд, вместо того чтобы молча
  висеть.
- `python -m offerbot check` ничего не отправляет — им можно крутить шаблоны
  безопасно.
