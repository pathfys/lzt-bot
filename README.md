# PMR Wallet

Некастодиальный криптокошелёк сети **TON** в одном HTML-файле: `pmr-wallet.html`.
Реальная генерация ключей, приём и отправка средств, P2P-маркет с блокировкой
средств под ордер. Интерфейс собран по макетам (тёмная синяя тема).

## Запуск

Просто откройте `pmr-wallet.html` в браузере (двойной клик) или разместите на
любом статическом хостинге / GitHub Pages / внутри Telegram Web App.
Сборка не требуется — крипто-библиотеки (`@ton/ton`, `@ton/crypto`, `qrcode`)
подгружаются с CDN при первом запуске, поэтому нужен интернет.

## Что реально работает (on-chain)

- **Создание кошелька** — настоящая 24-словная seed-фраза TON (`@ton/crypto`),
  кошелёк стандарта **Wallet v4R2**.
- **Импорт** существующей seed-фразы (24 слова).
- **Приём** — реальный адрес сети TON + QR. Пополнение TON и USDT.
- **Отправка** — реальные переводы в сети TON:
  - **TON (GRAM)** — нативная монета;
  - **USDT** — джеттон TEP-74 (mainnet).
- **Баланс** читается напрямую из блокчейна (toncenter), оценка в USD — CoinGecko.
- **Сети**: Mainnet и Testnet (переключатель в Настройках → Сеть). Тестовые
  монеты бесплатны через `@testgiver_ton_bot`.
- **Безопасность**: seed-фраза шифруется паролем (PBKDF2 + AES-GCM, WebCrypto)
  и хранится только в `localStorage` этого устройства. Пароль спрашивается при
  каждом запуске. Разработчик доступа к средствам не имеет.

## P2P

- Создание офферов (продажа/покупка), фильтры, срок закрепления.
- **Проверка баланса** и **блокировка средств**: при публикации оффера на
  продажу соответствующая сумма крипты резервируется локально
  (`Доступно = баланс on-chain − заблокировано`) — потратить её в другом месте
  приложения нельзя, пока оффер не снят.
- **Отпуск по сделке** — реальный on-chain перевод контрагенту на адрес сети TON.

## Ограничения (честно)

- **BTC и ETH** показаны в списке активов для соответствия макету, но находятся
  **вне сети TON** (другая система seed-фраз). On-chain приём/отправка для них в
  этом TON-кошельке не реализованы — баланс 0, помечены «вне сети TON».
- **Настоящий кросс-пользовательский эскроу** (средства держит третья сторона)
  требует смарт-контракта или бэкенда — в одном статическом HTML его нет.
  Поэтому «фриз» — это реальная **локальная** блокировка вашего баланса, а
  автоматическое сведение сделок между двумя пользователями не подключено.
- Демо-офферы (Blue Market, TON Desk) — примеры для витрины.

## Внимание

В режиме **Mainnet** вы работаете с настоящими деньгами, переводы необратимы.
Запишите seed-фразу офлайн — только она восстанавливает доступ. Для проверки
сначала используйте **Testnet**.
